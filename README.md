# MyPilot – AI-Powered Developer Assistant

**MyPilot** is an AI-powered developer assistant that enables developers to connect their GitHub repositories and interact with their codebase through natural-language conversations.

Built using Retrieval-Augmented Generation (RAG), MyPilot processes repository content, generates embeddings, and retrieves relevant code and documentation to provide context-aware responses using a large language model.

### Live Demo

**[Try MyPilot](https://my-pilot-nine.vercel.app/)**

### Key Features

- **GitHub Integration:** Connect GitHub repositories and access their codebase.
- **Repository Indexing:** Process source code and documentation for retrieval.
- **RAG Pipeline:** Generate embeddings, store vectors, and retrieve relevant context using similarity search.
- **AI-Powered Conversations:** Ask questions about a codebase and receive context-aware responses.
- **Real-Time Streaming:** Receive AI-generated responses through Server-Sent Events (SSE).

### Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Backend:** Java, Spring Boot, Spring AI
- **Database:** PostgreSQL, pgvector
- **AI:** Cloudflare Workers AI, Embeddings, Retrieval-Augmented Generation (RAG)
- **Infrastructure:** Docker, Flyway
